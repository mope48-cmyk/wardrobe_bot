Wardrobe Bot — Architecture

Telegram-бот «Гардероб»: aiogram 3 · LangGraph · SQLite · GigaChat/OpenRouter · Open-Meteo

Интерфейс

  • • Telegram Bot API (long polling)
  • • Обработка: текст, фото, альбомы, callback
  • • Частично фото / медиагруппы / редактирование

Логика

  • • LangGraph: граф состояний (35+ узлов)
  • • Маршрутизация: route_condition + интенты
  • • Сервисы: подбор, LLM, зрение, коллажи

Данные

  • • SQLite (aiosqlite) — 4 таблицы
  • • APScheduler: сводки, broadcast, стирка
  • • Модели: SegFormer · SigLIP · rembg
